🚀 About

GERARD GAMING ENGINE is a personal Android performance configuration project created by Gerard.

Its goal is to configure display refresh preferences, animation behavior and Android Game Mode for supported games.

⚡ Features

- 120 Hz maximum display refresh-rate request.
- Automatic minimum refresh-rate management.
- 1.25 animation scales.
- Android Game Mode performance request for Free Fire and Free Fire MAX.
- Custom Game Mode configurations for Blood Strike, Call of Duty: Mobile, Roblox and Minecraft.

📱 Tested Device

- Device: OPPO Reno 13F 5G
- Android: 16
- System: ColorOS 16
- Root manager: KernelSU
- Module version: 2.2

⚠️ Disclaimer

This project does not guarantee 120 FPS in every game or unlock game-specific FPS limitations.

Actual performance depends on device hardware, game restrictions, temperature and software compatibility.

Use at your own discretion. Always preserve Android thermal protections.
